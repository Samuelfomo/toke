# Intégration des besoins — Step 14

Remplacer `requirements/PlanningRequirementForm.vue` par la version fournie.

Chaque besoin possède désormais une section **Population éligible** :

- modes de planning `FIXED` / `ROTATING` ;
- relation au pool `ANY` / `MEMBER` / `NON_MEMBER`.

Pour une configuration sans pool, conserver `ANY`.
